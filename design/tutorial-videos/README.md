# SOPY Tutorial Videos

Short (≤1 min) bilingual Arabic/English social-media tutorials — one per app section — explaining how SOPY helps the end user.

- **[SOCIAL_POSTING_KIT.md](SOCIAL_POSTING_KIT.md)** — posting schedule, EN/AR captions, hashtag sets and cover-image naming (exported from the Cowork doc "SOPY Tutorial Videos — Social Posting Kit", Sep 27, 2026).

## Video set

All cuts are vertical 1080×1920 (Reels, TikTok, YouTube Shorts, Facebook Reels). Each has an Arabic (`AR`) and English (`EN`) cut plus a matching cover JPG (`_cover.jpg`).
